## 一句话介绍

**元数据管理**是一款离线运行的 Windows 桌面工具，用于查看、选择性清除与编辑 PDF、Office、图片文件中的元数据，帮助你在对外发送文件前去除隐私信息，或完成投标文档脱敏。

---

## 为什么需要它？

日常办公中，文件往往携带大量「看不见的信息」：

- Word / Excel / PPT 里的**作者、最后修改者、应用程序名称**（如 WPS、Microsoft Office）
- PDF 中的**创建者、生成程序、创建/修改时间**
- 图片中的 **EXIF、GPS 定位、拍摄设备** 等

这些信息在以下场景可能带来麻烦：

| 场景 | 风险 |
|------|------|
| 对外发送合同、方案 | 泄露个人或公司内部信息 |
| 投标 / 串标审查 | 多份标书因相同作者、修改者、软件痕迹被关联为同一人 |
| 发布图片、文档 | GPS、设备型号暴露拍摄地点与器材 |

**元数据管理**让你在本地即可完成「看元数据 → 选字段 → 清除或修改 → 导出干净文件」，无需上传云端，数据不出本机。

---

## 核心功能

### 元数据预览

- 打开文件即可查看全部可读元数据，按分组展示
- 支持拖拽添加、文件夹批量导入
- 拖入文件时**自动识别类型**并切换到 PDF / Office / 图片模块

### 选择性清除

- 每个字段可单独设置：**保留 / 清除 / 编辑**
- 清除项在字段名后显示红色 **×**，编辑项显示 **✎**
- 支持按分组「全保留 / 全清除」

### 字段编辑

- 可将作者、标题、公司等改为指定内容
- 适用于统一对外署名、替换敏感信息

### 快速预设

| 预设 | 说明 |
|------|------|
| **投标脱敏** | 清除作者、最后修改者、应用程序、公司、自定义属性等，降低标书被关联风险 |
| **隐私清除** | 清除身份信息、GPS、软件痕迹 |
| **全部清除** | 一键移除所有可编辑元数据 |

### 处理与报告

- 处理前后**对比视图**，变更一目了然
- 支持**覆盖原文件**或**另存到新目录**
- 可导出 **CSV / JSON** 处理报告，便于留档

### 其他

- 深色 / 浅色主题
- 离线运行，无需注册、无需联网

## 典型用法

### 投标文档脱敏

1. 打开 **Office** 模块，拖入 `.docx` / `.xlsx` / `.pptx`
2. 点击 **投标脱敏** 预设
3. 在右侧检查待清除字段，按需微调
4. 选择「另存到新目录」，点击 **应用更改**

### 对外发送 PDF 前清理

1. 打开 **PDF** 模块，导入 PDF
2. 预览元数据，勾选要清除的作者、时间、XMP 等字段
3. 应用更改并导出

### 发布图片前去定位

1. 打开 **图片** 模块，导入 JPG / PNG
2. 使用 **隐私清除** 或手动清除 GPS、EXIF 作者信息
3. 另存后发布

## 常见问题

**Q：文件会上传到服务器吗？**  
A：不会。所有处理均在本地完成，离线可用。

**Q：清除后能恢复吗？**  
A：覆盖原文件时会自动备份到应用数据目录，可在结果列表点「撤销」还原；更稳妥的做法是优先「另存到新目录」。

**Q：为什么拖入 Office 文件后界面切到了 Office 模块？**  
A：软件会自动识别文件类型并切换到对应模块，避免格式不匹配。

**Q：软件收费吗？**  
A：采用 MIT 开源许可，由墨点 inkdot 提供，可自由使用与分发。

**Q：处理带宏或数字签名的 Office 文件会怎样？**  
A：宏（vbaProject.bin）会原样保留，但 Office 文档的数字签名在重新打包后必然失效——这是 Office 签名机制决定的，任何元数据修改都会导致签名失效。如需保留签名，请勿处理该文件。

**Q：单次能处理多少文件？**  
A：单次最多 500 个；目录批量扫描深度上限 8 层、条数上限 5000，超出会提示分批。
